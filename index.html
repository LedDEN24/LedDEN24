OSINT для компаний и ИП РФ

RF Open Source Due Diligence Desk

Одностраничное веб-приложение для проверки контрагентов по официальным и публичным источникам, оценки risk flags и сборки нейтрального отчета без профилирования частных лиц.

Приложение не предназначено для проверки частных лиц и не должно использоваться для составления досье на людей.

        4. Нейтральный OSINT-дашборд и отчет

        Отмечайте просмотренные источники, ведите заметки и экспортируйте нейтральный отчет для внутренней проверки контрагента.
