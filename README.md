# RF Open Source Due Diligence Desk

Статическое веб-приложение для безопасной проверки **компаний и ИП РФ** по
открытым источникам. Приложение покрывает три сценария:

1. **Проверка компаний/ИП по открытым реестрам**
2. **Комплаенс-проверка контрагентов с risk flags**
3. **Нейтральный OSINT-дашборд и экспорт отчета**

> Важно: приложение **не предназначено для проверки частных лиц** и не должно
> использоваться для составления досье на людей.

## Что внутри

- карточка кейса: тип объекта, ИНН, ОГРН, домен, отрасль, глубина проверки;
- библиотека официальных и публичных источников с фильтрами;
- автоматически собираемый маршрут проверки по введенным данным;
- локальный risk score по отмеченным red flags;
- дашборд прогресса по источникам;
- экспорт краткого брифа в Markdown;
- экспорт полного нейтрального отчета в Markdown и JSON;
- локальное сохранение состояния в `localStorage`.

## Источники, включенные в приложение

- ЕГРЮЛ / ЕГРИП (ФНС)
- Прозрачный бизнес (ФНС)
- Бухгалтерская отчетность (ФНС)
- Федресурс
- Картотека арбитражных дел
- ФССП - исполнительные производства
- ЕИС / Госзакупки
- Единый реестр проверок Генпрокуратуры
- Росаккредитация
- Банк России - справочник участников финансового рынка
- OFAC Sanctions Search
- WHOIS / RDAP
- Поиск по новостям и отраслевым публикациям

## Быстрый запуск

Приложение не требует сборки и внешних зависимостей.

### Вариант 1: открыть файл напрямую

Откройте `index.html` в браузере.

### Вариант 2: запустить локальный static server

```bash
python3 -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

## Как работать

1. Заполните карточку объекта проверки.
2. Просмотрите рекомендованный маршрут по открытым источникам.
3. Отмечайте найденные risk flags в блоке комплаенса.
4. Помечайте просмотренные источники.
5. Заполняйте факты и нейтральное заключение.
6. Экспортируйте бриф или полный отчет.

## Ограничения и безопасное использование

- приложение не делает автоматических запросов в реестры и не обходит защиту;
- введенные данные хранятся только локально в браузере;
- перед автоматизацией запросов к любому реестру проверьте условия использования
  источника;
- не включайте в отчеты избыточные персональные данные;
- сверяйте критичные выводы минимум по двум независимым источникам.
