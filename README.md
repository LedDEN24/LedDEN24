# Legal Checks RF

Django-проект с интерфейсом для легальных проверок по РФ на основе официальных источников и уже подготовленного комплекта документов.

## Что есть в проекте

- веб-интерфейс на Django;
- страницы чеклистов и шаблонов, которые читаются из папки `legal-checks-rf`;
- страница официальных источников;
- JSON API с перечнем официальных реестров и правил использования.

## Быстрый запуск

```bash
python3 -m pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py runserver
```

После запуска откройте:

- `/` — главная страница;
- `/sources/` — официальные источники;
- `/api/sources/` — JSON API;
- `/documents/<slug>/` — конкретный документ.

## Контентный набор

- `legal-checks-rf/README.md` — быстрый старт и сценарии использования;
- `legal-checks-rf/checklists/self-check.md` — самопроверка физлица;
- `legal-checks-rf/checklists/third-party-with-consent.md` — законная проверка третьего лица;
- `legal-checks-rf/templates/open-registries-consent.md` — согласие на проверку по открытым реестрам;
- `legal-checks-rf/templates/credit-report-submission-consent.md` — согласие на передачу кредитного отчета самим субъектом;
- `legal-checks-rf/templates/screening-request-form.md` — внутренняя карточка запуска проверки;
- `legal-checks-rf/data/official_sources.json` — перечень официальных источников и правил использования.

## Важно

- проект ориентирован на законное использование: самопроверка, комплаенс, проверка контрагента, кадровая или договорная проверка при наличии законного основания;
- кредитную историю нельзя получать из "чужих баз" — для нее нужен предусмотренный законом порядок;
- материалы не заменяют индивидуальную юридическую консультацию.
