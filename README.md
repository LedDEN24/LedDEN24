# Legal Checks RF

Готовый мини-проект для легальных проверок по РФ без серых баз и без несанкционированного доступа к персональным данным.

В комплект входят:

- обзор официальных реестров и их ограничений;
- чеклист самопроверки;
- чеклист проверки третьего лица по открытому контуру и по согласию;
- шаблоны согласия и формы запуска проверки;
- JSON-файл с официальными источниками для дальнейшей автоматизации.

## Структура

- `legal-checks-rf/README.md` — быстрый старт и сценарии использования;
- `legal-checks-rf/checklists/self-check.md` — самопроверка физлица;
- `legal-checks-rf/checklists/third-party-with-consent.md` — законная проверка третьего лица;
- `legal-checks-rf/templates/open-registries-consent.md` — согласие на проверку по открытым реестрам;
- `legal-checks-rf/templates/credit-report-submission-consent.md` — согласие на передачу кредитного отчета самим субъектом;
- `legal-checks-rf/templates/screening-request-form.md` — внутренняя карточка запуска проверки;
- `legal-checks-rf/data/official_sources.json` — перечень официальных источников и правил использования.

## Важно

- Материалы ориентированы на законное использование: самопроверка, комплаенс, проверка контрагента, кадровая или договорная проверка при наличии законного основания.
- Кредитную историю нельзя получать из "чужих баз". Для нее нужен предусмотренный законом порядок.
- Это не юридическое заключение, а рабочий шаблонный комплект.
