# Шаблон согласия на проверку по открытым официальным реестрам

Ниже приведен рабочий шаблон. Перед использованием его нужно адаптировать под вашу организацию, цель проверки и фактический перечень данных.

---

## СОГЛАСИЕ

на обработку персональных данных и проведение проверки по открытым официальным источникам

Я, `[ФИО субъекта]`, дата рождения `[дд.мм.гггг]`, паспорт/иной документ `[реквизиты при необходимости]`, настоящим даю согласие оператору `[полное наименование организации / ФИО ИП / ФИО лица]`, ИНН `[при наличии]`, адрес `[адрес]`, на обработку моих персональных данных в целях проведения `[кадровой / договорной / комплаенс / иной]` проверки.

### 1. Цель обработки

Целью обработки является:

- проверка сведений, имеющих значение для принятия решения о `[трудоустройстве / заключении договора / допуске к процедуре / иной цели]`;
- документирование результатов проверки в рамках внутренних процедур оператора;
- соблюдение требований применимого законодательства и внутренних регламентов оператора.

### 2. Перечень данных

Для указанной цели могут обрабатываться следующие данные:

- фамилия, имя, отчество;
- дата рождения;
- регион проживания или регистрации;
- ИНН и иные идентификаторы, если они предоставлены мною и нужны для точного поиска;
- сведения, содержащиеся в открытых официальных государственных и судебных реестрах.

### 3. Источники проверки

Проверка может проводиться только по следующим открытым официальным источникам:

- Федеральная служба судебных приставов — `https://fssp.gov.ru/iss/ip/`;
- ГАС "Правосудие" / sudrf — `https://ej.sudrf.ru/`, `https://sudrf.ru/`;
- Картотека арбитражных дел — `https://kad.arbitr.ru/`;
- Федресурс — `https://fedresurs.ru/`.

### 4. Действия с данными

Оператор вправе осуществлять следующие действия:

- получение;
- запись;
- систематизацию;
- хранение;
- уточнение;
- использование;
- обезличивание при необходимости;
- удаление и уничтожение по достижении цели обработки или при отзыве согласия, если отсутствует иное законное основание хранения.

### 5. Срок действия согласия

Согласие действует до `[дата / событие]`, но в любом случае не дольше, чем это требуется для цели проверки и исполнения обязанностей оператора.

### 6. Порядок отзыва

Согласие может быть отозвано путем направления письменного заявления по адресу `[адрес / email / иной канал]`.

### 7. Подтверждение субъекта

Мне разъяснено, что:

- проверка проводится только по открытым официальным источникам;
- кредитная история не запрашивается в рамках данного согласия;
- я вправе запросить сведения о составе обрабатываемых данных и отозвать согласие в установленном порядке.

`[ФИО субъекта]`

### Краткая памятка по заполнению

- если оператором выступает компания, укажите полное юридическое наименование;
- если ИНН не нужен для поиска, не включайте его в перечень данных;
- если проверка идет только по двум реестрам, уберите лишние источники;
- не добавляйте в этот шаблон пункты о кредитной истории, если фактически ее не обрабатываете.
